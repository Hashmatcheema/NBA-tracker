# Vendored License Texts

Drop the verbatim license file from each upstream project into this directory
before cutting a public release:

- `onnxruntime_LICENSE.txt` — copy from
  https://github.com/microsoft/onnxruntime/blob/v1.17.3/LICENSE
- `cuda_EULA.txt` — copy from your installed CUDA Toolkit's
  `EULA.txt` (typically under `C:\Program Files\NVIDIA GPU Computing Toolkit\CUDA\v11.8\`)
- `cudnn_SLA.txt` — copy from
  https://docs.nvidia.com/deeplearning/cudnn/sla/index.html
- `ultralytics_LICENSE.txt` — copy from
  https://github.com/ultralytics/ultralytics/blob/main/LICENSE
- `pyqt6_LICENSE.txt` — copy from your PyQt6 installation
  (Python `site-packages/PyQt6/LICENSE`)

Once populated, the `THIRD_PARTY_LICENSES.md` summary at the repo root will
correctly reference these files.
